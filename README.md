# Poorgram Web
[EN](./README_EN.)
Клиент для любой картошки на Quart & Telethon
## Работа с инстансами
Официального инстанса у проекта на данный момент **НЕТ**. При использовании каких-либо неофициальных публичных инстансов, используйте прокси для работы, дабы избежать блокировок и/или утери аккаунта. Также учитывайте, что неофициальные публичные инстансы могут иметь вредоносный код и собирать ваши данные.

При поднятии своего инстанса и использовании его без прокси, обязательно убедитесь, что IP вашего сервера не находится под подозрением у Telegram. Для этого попробуйте войти через любой аккаунт, к которому можно будет легко восстановить доступ и/или его не будет жалко потерять.
## Что это?
Если кратко, то это Telegram клиент в браузере, но все действия выполняются на сервере, клиент лишь отдаёт команды. Благодаря этому, можно использовать Telegram на устаревших телефонах, которые не имеют какой-либо реализации MTProto и/или могут вовсе её не потянуть. Требуется лишь браузер с поддержкой куки. Наглядный аналог проекта - MPGram.
## Развёртывание через Docker
Создайте `.env`, используя шаблон .env.template

Для разработки: `docker compose up -d --build`. Стандартный docker-compose сильно упрощён и почти не отличается от `pip install -r requirements.txt && python app.py`.

Для продакшена используется docker-compose-prod.yml: `docker compose -f docker-compose-prod.yml up -d --build`. Тут используется uvicorn, nginx и добавлены healthcheck.

**ВАЖНО:** По умолчанию, в продакшене нет HTTPS. Если вам нужен HTTPS, то скопируйте сертификат и ключ в папку nginx (как cert.crt и private.key соответственно) и отредактируйте yml и nginx.conf для работы с HTTPS (можно расдокументировать уже имеющиеся части кода)
